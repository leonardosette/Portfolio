# Checklist de Testes e Lançamento

Testes feitos antes de considerar o PortfolioHUB pronto para uso real. Marque conforme for validando.

## Conteúdo

- [ ] Os 7 links "Abrir no GitHub" abrem o repositório certo (sem erro 404)
- [ ] Link do LinkedIn preenchido e funcionando
- [ ] Vídeo do YouTube aparece na seção de apresentação
- [ ] README de cada projeto existe e está legível
- [ ] Sem textos de exemplo ou campos vazios na página

## Funcionamento

- [ ] Menu abre e fecha no celular
- [ ] Botão de tema claro/escuro funciona e lembra a escolha
- [ ] Rolagem até cada seção pelo menu
- [ ] Console do navegador sem erros (F12 → Console)

## Compatibilidade

- [ ] Chrome
- [ ] Edge ou Firefox
- [ ] Celular (Android ou iPhone)
- [ ] Largura estreita (janela reduzida)

## Publicação

- [ ] Página abre em https://leonardosette.github.io/Portifolio/
- [ ] Alterações novas aparecem após `git push` (aguardar alguns minutos)
- [ ] Repositório público

## Segurança

- [ ] Nenhuma senha ou token no código (`git log -p | grep -i "token\|senha\|password"`)
- [ ] `.gitignore` presente
- [ ] Itens de `docs/configuracao-seguranca-acesso.md` concluídos
